## First objective

Produce a reproducible model that beats the frozen baseline on source-disjoint How2Sign and signer-disjoint FLEURS development data and remains compatible with the published UMI bundle runtime. Keep a clean experiment ledger so a result can be reconstructed, licensed, packaged and submitted to the public-model track.

Start by reproducing baseline inference and measuring its task-level errors. Then make one measurable change at a time. Favor data quality, split integrity and a strong fingerspelling path over blind hyperparameter sweeps.

The public request includes a fingerspelling/short-utterance/continuous stratum, but the currently pinned native worker passes only video bytes and a deadline to the model runtime. A task-specific fingerspelling route therefore needs a separately verified worker-interface change or an independently tested video-only classifier; changing a model bundle alone will not expose the stratum. Keep that work separate from the active miner.
